Reference Guide

Introduction to EUC² & TDES

Welcome to the technical reference documentation. The Test Delivery and Evaluation System (TDES) is built to orchestrate, deliver, and grade programming exercises inside isolated container sandboxes.

All operations are driven via the euc2 CLI binary. Exercises follow a standardized, declarative schema configured in a manifest.json file, which interfaces with a simple Makefile contract.

euc2 CLI

euc2 CLI Command Suite

Automate execution tasks using the euc2 command-line tools. Click each tab below to view parameters and output examples.

euc2 init

Initialize an exercise by lab ID and version from local packages into a working directory.

Arguments: <id-with-version> <working-directory>
Usage & Command Output
$ euc2 init go101-lab01@1.1.0 ./my-stack-exercise
Exercise initialized in ./my-stack-exercise
