From Curriculum to Grades: The Automated Journey

A frictionless, step-by-step cycle that bridges the gap between active student coding and reliable host evaluation.

01

Pick or Define

Select from our standard CS curriculum libraries, author custom templates following the open standard, or request custom exercises tailored for your classroom.

02

Distribute Files

Deliver the public package files to student machines instantly. Works over local network folders, central registries, or simple USB pen drives for air-gapped rooms.

03

Solve & Submit

Students write code in their favorite editor, verify logic locally with instant tests, and seal submissions in one click using secure X25519-encrypted envelopes.

04

Sandbox Grading

The host system extracts code, runs hidden private tests in isolated container sandboxes, calculates scores, and generates structured grading reports instantly.

Why CS Departments Choose TDES

A lightweight, offline-first grading engine designed to seamlessly fit into your existing laboratory workflow.

Lightweight & Minimal Setup

Avoid the headache of deploying heavy database servers, configuring user authentication, or maintaining complex cloud instances. TDES runs as a single, compiled tool with zero background dependencies. Just copy it over and start grading.

Free & Fully Open Source

Built with absolute transparency. TDES is entirely free to use under an open-source license, meaning no vendor lock-in, zero subscription costs, and full freedom to audit and customize the code to fit your university's exact curriculum needs.

Works 100% Offline

Protect your exams from server crashes, slow Wi-Fi networks, and local outages. TDES executes and grades submissions completely offline, making it the perfect fit for secure, air-gapped computer labs.

Complements Your Existing Workflow

You don't need to rebuild your curriculum or throw away your current systems. TDES acts as a lightweight, secure helper that integrates directly into your existing command-line setups, file directories, or lab submission portals without friction.
