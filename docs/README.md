# TDES Documentation Site

Documentation portal for the **Lab Test Evaluation and Delivery System (TDES)**, built with [Astro](https://astro.build).

- **GitHub Repository**: [https://github.com/piyush-bit/Lab-Test-Evaluation-and-Delivery-System](https://github.com/piyush-bit/Lab-Test-Evaluation-and-Delivery-System)

## 🧞 Commands

All commands are run from the `docs` directory:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `http://localhost:4321` |
| `npm run build`           | Build production site to `./dist/`               |
| `npm run preview`         | Preview build locally                            |
